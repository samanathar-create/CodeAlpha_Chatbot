# CodeAlpha Rule-Based Chatbot

## About the Project

This project is a simple rule-based chatbot developed in Python for the CodeAlpha Python Programming Internship. It responds to user messages using predefined rules and conditions.

## Features

* Interacts with users through text.
* Responds to predefined questions and greetings.
* Uses conditional statements to identify user input.
* Provides a simple command-line interface.

## Technologies Used

* Python 3

## How to Run

1. Install Python 3.
2. Download this repository.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python "Rule-Based Chatbot.py"
```

## Purpose

This project demonstrates basic Python concepts, including strings, conditional statements, and user input handling.
